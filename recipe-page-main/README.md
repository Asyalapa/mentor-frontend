# Frontend Mentor – Recipe page Solution

This is a solution to the [Recipe page Solution challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/recipe-page-KiTsR8QQKm).  

## 🔗 Live Site  

- [Live Demo](https://asyalapa.github.io/mentor-frontend/recipe-page-main/)  
 

### 🛠 Built with  

- **HTML**  
- **CSS**  
- **Flexbox**  
- **Media queries**  
- **Google Fonts (imported)**

### 📝 Development Steps  

1. Started with a **desktop-first approach**, designing for larger screens initially.  
2. Built the **HTML structure** using semantic tags like `<main>`, `<article>`, and `<footer>`.  
3. Imported **Google Fonts** (`Young Serif` and `Outfit`) for consistent typography.  
4. Styled the layout using **CSS variables** for colors, fonts, spacing, and dimensions to ensure consistency.  
5. Applied **Flexbox** for alignment and spacing of sections like ingredients and instructions.  
6. Added **media queries** to adapt the design for mobile devices.  
7. Ensured **pixel-perfect accuracy** by carefully matching colors, sizes, and spacing from the design image.  
8. Validated the code using **HTML & CSS validators** for clean and error-free markup.

### 🚀 Challenges & Learnings  

Matching colors and sizes from the design image without a Figma file was tricky and required precise adjustments. Adapting the omelette image for mobile devices also posed challenges, as I initially didn't account for how scaling would affect the layout. Working with spacing and alignment across different screen sizes taught me the importance of thorough planning. Overall, this project reinforced the value of **CSS variables**, **responsive design**, and attention to detail!
