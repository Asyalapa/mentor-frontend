# Frontend Mentor – Blog Preview Card Solution

This is a solution to the [Blog Preview Card challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/blog-preview-card-ckPaj01IcS).  

## 🔗 Live Site  

- [Live Demo](https://asyalapa.github.io/mentor-frontend/blog-preview-card/)  
 

### 🛠 Built with  

- **HTML**  
- **CSS**  
- **Flexbox**  
- **Media queries**  
- **Custom Fonts (Converted from TTF to WOFF2)**

### 📝 Development Steps  

1. Decided to try a **mobile-first** approach.  
2. Created the **HTML structure**, following semantic markup.  
3. Converted **TTF fonts to WOFF2** for better performance and loaded them via @font-face.
4. Styled the card layout using **Flexbox** for proper alignment.
5. Added **hover effect** for the title using a **media query for hover**.
6. Ensured **pixel-perfect accuracy**, comparing with the design.
7. Expanded to **desktop layout**, adjusting styles for larger screens.
8. Validated the code using **HTML & CSS validators**.

### 🚀 Challenges & Learnings
One of the trickiest parts was working with **SVGs** as background images. Handling fill and making them appear correctly took extra effort. If anyone knows a great tutorial or resource on **best practices for SVG in CSS**, I'd love to check it out!
