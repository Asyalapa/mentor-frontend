# Frontend Mentor – Social Links Profile Solution

This is a solution to the [Social Links Profile Solution challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ).  

## 🔗 Live Site  

- [Live Demo](https://asyalapa.github.io/mentor-frontend/social-links-profile-main/)  
 

### 🛠 Built with  

- **HTML**  
- **CSS**  
- **Flexbox**  
- **Media queries (for hover effects and responsiveness)**  
- **Google Fonts (imported)**

### 📝 Development Steps  

1. Decided to try a **mobile-first** approach.  
2. Created the **HTML structure**, following semantic markup.  
3. Converted **TTF fonts to WOFF2** for better performance and loaded them via @font-face.
4. Styled the card layout using **Flexbox** for proper alignment.
5. Added **hover effect** for the title using a **media query for hover**.
6. Ensured **pixel-perfect accuracy**, comparing with the design.
7. Expanded to **desktop layout**, adjusting styles for larger screens.
8. Validated the code using **HTML & CSS validators**.

6. Focused on **accessibility** by improving tab navigation and active states.
7. Experimented with styling the parent `<li>` when the child `<a>` is **focused or active** but faced challenges.

### 🚀 Challenges & Learnings
One of the most challenging parts was styling the parent `<li>` when the child `<a>` was in `:focus` or `:active` state. I explored different approaches, including `:focus-within` and `:has()`, to achieve the desired effect. If anyone has more insights or best practices, I'd love to learn more!
